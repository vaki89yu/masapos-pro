# 🌽 MasaPOS Pro

Sistema POS profesional para **fábricas de masa, molinos y tortillerías**.

### Características
- 💰 **Venta en Tienda**: $10.00/kg
- 🏍️ **Reparto en Moto**: $11.00/kg
- 🔢 Selectores rápidos del 1kg al 10kg
- 🪙 Calculadora de billetes y monedas mexicanas
- 📊 Dashboard con estadísticas
- 🌾 Bitácora de molienda y nixtamal
- 💼 Corte de caja (Corte X / Corte Z)
- 🤝 Cuentas de crédito para taquerías

### Stack
- Next.js 16 (App Router)
- Drizzle ORM + PostgreSQL
- Tailwind CSS v4
- Lucide React icons
